# TESLA Management — Project Overview (Initial Intake)

**บันทึกเมื่อ:** 9 กันยายน 2569
**สถานะ:** อยู่ระหว่างรวบรวม Requirement เบื้องต้น — รายละเอียดแต่ละ Module ยังไม่ครบ

## วัตถุประสงค์โครงการ

โครงการ TESLA Management เป็นระบบสำหรับบริหารจัดการแบบประกัน แคมเปญ และช่องทางการขาย ประกอบด้วย 5 Module หลัก:

| # | Module | คำอธิบายเบื้องต้น |
|---|--------|-------------------|
| 1 | Dashboard | สรุปกรมธรรม์ที่ลูกค้าซื้อ ใช้ติดตามสถานะกรมธรรม์ — รายละเอียดกรมธรรม์, ผู้เอาประกัน, ผู้ชำระเบี้ย, แบบประกันที่ซื้อ, ทุนประกัน, เบี้ยประกัน, วันที่ทำกรมธรรม์, สถานะกรมธรรม์ |
| 2 | Package setting | จัดทำข้อมูลแบบประกันเพื่อนำไปขาย ทั้งช่องทาง Online และ Agent |
| 3 | Campaign setting | ตั้งค่า Campaign และ Promotion |
| 4 | Seller list | Mapping ตัวแทน — ช่องทางที่ขาย, สินค้าที่ขายได้, แคมเปญ/โปรโมชั่นที่ได้รับ |
| 5 | Master setup | ข้อมูล Master ที่ใช้ในระบบ (สร้างเองหรือ Sync จากระบบอื่น) |

## เอกสารที่ต้องจัดทำ

1. BRD (Business Requirements Document)
2. FRS (Functional Requirements Specification)
3. Workflow
4. Business Journey
5. Backlog
6. Scenario Test
7. Project Timeline

## หมายเหตุ

- โครงการนี้แยกจากโครงการ TESLA เดิม (iApply sales flow) แม้จะใช้ชื่อ TESLA ร่วมกัน — ความสัมพันธ์ระหว่างสองระบบอยู่ระหว่างยืนยันกับผู้ใช้งาน
- รายละเอียดเชิงลึกของแต่ละ Module จะทยอยได้รับจากผู้ใช้งานในการสนทนาถัดไป ก่อนเริ่มจัดทำ BRD ฉบับสมบูรณ์
