# Overview — Target & Summarize Value Selling Spec (Draft v0.2)

**บันทึกเมื่อ:** 24 กันยายน 2569 (v0.2 — ปิด OQ-O01…O03)
**สถานะ:** Draft — ยืนยันหลักการครบ (OV-01…OV-07) ไม่มี Open Question ค้าง
**อ้างอิง:** Grant status (BR-CP-004/005), Referral tracking (BR-CP-009), People (07), Content/Campaign approval (04–06)

## 0. Confirmed Decisions (24 ก.ย. 2569)

| # | ประเด็น | การตัดสินใจ |
|---|---|---|
| OV-01 | แหล่ง Target | **ทั้งสองแบบ** — ระดับ Package ใช้ `sale_Target` จาก Package payload; ระดับ ช่องทาง / กลุ่ม / ผู้ขาย ตั้งเพิ่มใน TESLA Management |
| OV-02 | ตัวชี้วัดยอดขาย | **ทั้ง 3 แบบ** — FYP (เบี้ยปีแรก), APE (เบี้ยรายปี), จำนวนกรมธรรม์; ผู้ใช้สลับดูได้ทั้งหน้า |
| OV-03 | มุมมองตาม Role | **หน้าเดียว เนื้อหาตามสิทธิ์** — ผู้บริหารเห็น OV-A ถึง OV-E; Maker/Approver เห็น OV-F (งานของตัวเอง) + OV-D |
| OV-04 | ความสดของข้อมูล | **Real-time** — ตัวเลขเปลี่ยนทันทีที่มีกรมธรรม์/สถานะเข้ามา |
| OV-05 | หน่วยของ `sale_Target` (OQ-O01) | **FYP หน่วยบาท ตลอดช่วง start_Date – end_Date ของ Package** (end_Date = null → นับจนกว่าจะมีวันสิ้นสุด) — เทียบได้เฉพาะเมื่อเลือกตัวชี้วัด FYP; APE / จำนวนกรมธรรม์ ระดับ Package แสดง "–" |
| OV-06 | สูตร APE (OQ-O02) | **Σ(เบี้ยงวด × จำนวนงวดต่อปี) + 10% × เบี้ยชำระครั้งเดียว** |
| OV-07 | ขอบเขตข้อมูลผู้บริหาร (OQ-O03) | **เห็นทุก Package** ในเฟสแรก |

## 1. โครงหน้า

| Section | เนื้อหา | ข้อมูลมาจาก | Role |
|---|---|---|---|
| OV-A สรุปผู้บริหาร (KPI tiles) | ยอดขายอนุมัติแล้ว vs Target (%), กรมธรรม์ เข้าเงื่อนไข / อนุมัติ, อัตราอนุมัติ, งบ Campaign จอง / ใช้จริง / คงเหลือ, ต้นทุนต่อกรมธรรม์ (งบใช้จริง ÷ กรมธรรม์อนุมัติ), ยอดขาย ÷ งบใช้จริง | กรมธรรม์, Grant, Target | ผู้บริหาร |
| OV-B แนวโน้มยอดขาย | ยอดขายรายวัน / สัปดาห์ / เดือน เทียบเส้น Target แยกตามช่องทาง | กรมธรรม์, Target | ผู้บริหาร |
| OV-C ผลงานราย Package | Target (sale_Target), ยอดจริง, % ถึงเป้า, กรมธรรม์, Campaign ที่ Active | Package, กรมธรรม์ | ผู้บริหาร |
| OV-D ผลงานราย Campaign | Eligible / Confirmed / Released / Clawed back, งบ, % โควตาที่ใช้, วันหมดอายุ | Grant | ผู้บริหาร, Maker, Approver |
| OV-E ผลงานรายกลุ่ม / ผู้ขาย | Target vs ยอดจริง, กรมธรรม์, Referral (คลิก → ใบคำขอ → อนุมัติ), Top 10 ผู้ขาย | People, Referral, Target | ผู้บริหาร |
| OV-F งานที่ต้องทำ & ความเคลื่อนไหว | รออนุมัติ (Content / Campaign), Campaign หมดใน 7 วัน, โควตา ≥ 80%, ใบอนุญาตหมดใน 30 วัน, ผู้ขายยังไม่มีกลุ่ม, กิจกรรมล่าสุด | ทุกเมนู | Maker, Approver |

**ตัวกรองทั้งหน้า:** ช่วงวันที่ (ค่าเริ่มต้น = เดือนนี้), ช่องทาง, Package, ประเภทสินค้า, ประเภท Campaign · **สลับตัวชี้วัด:** FYP / APE / จำนวนกรมธรรม์

## 2. นิยามตัวชี้วัด (สำหรับ SA)

| ID | ตัวชี้วัด | สูตร | หมายเหตุ |
|---|---|---|---|
| KPI-01 | FYP อนุมัติแล้ว | Σ เบี้ยปีแรกของกรมธรรม์สถานะอนุมัติ ในช่วงวันที่ยื่นใบคำขอที่เลือก | ไม่รวมยกเลิก Free look |
| KPI-02 | APE อนุมัติแล้ว | Σ (เบี้ยงวด × จำนวนงวดต่อปี) + 10% × เบี้ยชำระครั้งเดียว (OV-06) | งวดต่อปี: รายปี 1, ราย 6 เดือน 2, ราย 3 เดือน 4, รายเดือน 12 |
| KPI-03 | จำนวนกรมธรรม์ | นับกรมธรรม์ตามสถานะ | แสดงทั้ง "เข้าเงื่อนไข" และ "อนุมัติ" |
| KPI-04 | % ถึงเป้า | ยอดจริง ÷ Target × 100 | Target ต้องเป็นตัวชี้วัดเดียวกัน; ระดับ Package เทียบได้เฉพาะ FYP (OV-05); ไม่มี Target → "–" |
| KPI-05 | อัตราอนุมัติ | กรมธรรม์อนุมัติ ÷ ใบคำขอที่มีผลพิจารณาแล้ว | |
| KPI-06 | งบ Campaign | จอง / ใช้จริง / คงเหลือ ตาม BR-CP-005 | รวมเฉพาะ Campaign ที่มีงบ |
| KPI-07 | ต้นทุนต่อกรมธรรม์ | งบใช้จริง ÷ กรมธรรม์อนุมัติที่ได้สิทธิ์ | |
| KPI-08 | ยอดขายต่องบ | FYP (หรือ APE) ของกรมธรรม์ที่ได้สิทธิ์ ÷ งบใช้จริง | |
| KPI-09 | Referral funnel | คลิก → ใบคำขอ → อนุมัติ และ % แต่ละขั้น | BR-CP-009 |

## 3. Business Requirements

| ID | Requirement | Priority | Rationale | Acceptance Criteria |
|---|---|---|---|---|
| BR-OV-001 | แสดง Section ตามสิทธิ์ Role (OV-03) | Must | หน้าเดียวแต่ข้อมูลไม่เกินสิทธิ์ | ผู้บริหารเห็น A–E (ทุก Package — OV-07); Maker/Approver เห็น D + F; ข้อมูล Section ที่ไม่มีสิทธิ์ไม่ถูกส่งมาที่หน้าจอ (ไม่ใช่แค่ซ่อนด้วย CSS) |
| BR-OV-002 | สลับตัวชี้วัด FYP / APE / จำนวนกรมธรรม์ (OV-02) | Must | ผู้ใช้แต่ละฝ่ายใช้ตัวชี้วัดต่างกัน | สลับแล้วทุก Section และ Target เปลี่ยนตาม; จำค่าที่เลือกไว้ต่อผู้ใช้ |
| BR-OV-003 | ดึง Target ระดับ Package จาก `sale_Target` (OV-01, OV-05) | Must | ไม่ตั้งซ้ำ | แสดงค่าจาก Package ล่าสุดที่ Sync เป็น FYP บาท ตลอดอายุ Package; null → "ยังไม่มี Target" |
| BR-OV-004 | ตั้ง Target ระดับ ช่องทาง / กลุ่ม / ผู้ขาย ใน TESLA Management (OV-01) | Must | ติดตามผลงานละเอียดกว่า Package | หน้า "ตั้ง Target": เลือกระดับ + ตัวชี้วัด + งวด (รายเดือน) + ค่า; Import/Export Excel ได้; ผลรวม FYP ของระดับล่างเกิน sale_Target ของ Package → เตือน (ไม่บล็อก) |
| BR-OV-005 | อัปเดตตัวเลขแบบ Real-time (OV-04) | Must | ผู้บริหารติดตามระหว่างวัน | ข้อมูลกรมธรรม์/สถานะใหม่แสดงบน Overview ภายใน 1 นาที โดยไม่ต้อง Refresh หน้า; แสดง "อัปเดตล่าสุด" |
| BR-OV-006 | Drill-down | Should | จากภาพรวมไปหาสาเหตุ | คลิก KPI / แถว → ไปหน้ารายละเอียดที่กรองไว้แล้ว (เช่น คลิก Campaign → รายการ Grant) |
| BR-OV-007 | งานที่ต้องทำ (OV-F) | Must | ลดงานค้าง | แสดงเฉพาะงานของผู้ใช้/หน่วยงาน; คลิกไปหน้าอนุมัติ/แก้ไขได้ทันที; นับจำนวนตรงกับรายการจริง |
| BR-OV-008 | Export | Should | ใช้ประชุม/รายงาน | Export Section ที่เห็นเป็น Excel ตามตัวกรองปัจจุบัน |

## 4. Data เพิ่มเติม

| Policy Sales (จาก API — Mock ใน Prototype) | application_No, policy_No, package_Code, channel_Code, seller_Code, referral_Link_Id, วันที่ยื่นใบคำขอ, วันที่อนุมัติ, FYP, เบี้ยงวด, payment_Mode, สถานะ |
