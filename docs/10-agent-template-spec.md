## 2. Section ใหม่

| ID | Section | แสดงที่ | Field หลัก | Rule |
|---|---|---|---|---|
| AG-01 | การ์ดตัวแทน | หน้าลูกค้า | ชื่อ, เลขที่ใบอนุญาต, สาขา (DRV จากฐานข้อมูลผู้ขาย); ช่องทางติดต่อที่แสดง โทร/LINE/อีเมล (CMS); ตำแหน่งบนหน้า | แสดงเฉพาะตัวแทนที่พร้อมขาย (PM-02); ตัวแทนแก้เองไม่ได้ |
| AG-02 | จุดขาย & กลุ่มลูกค้าเป้าหมาย | **เฉพาะตัวแทน** (หน้า Referral links) | Tag กลุ่มเป้าหมาย; จุดขาย + วิธีนำเสนอ (1–N); FAQ / การตอบข้อโต้แย้ง (1–N) | ไม่แสดงต่อลูกค้า |
| AG-03 | Sales kit | **เฉพาะตัวแทน** | ชื่อเอกสาร, ไฟล์ (.pdf/.jpg/.png ≤ 10 MB), ส่งต่อให้ลูกค้าได้ (ได้/ไม่ได้) | เอกสาร "ส่งต่อได้" มีปุ่มแชร์ |
| AG-04 | ชุดแชร์โซเชียล | **เฉพาะตัวแทน** (ใช้แชร์ออกไป) | รูป 1:1 / 9:16 / 1.91:1; ข้อความสำเร็จรูป + ตัวแปร {ชื่อตัวแทน} {เบอร์โทร} {ลิงก์}; Hashtag; OG title (DRV จาก OB-02) | อนุมัติพร้อม Content; ตัวแทนแก้ข้อความเองไม่ได้ |

## 3. Requirement

| ID | Requirement | Priority | Acceptance Criteria |
|---|---|---|---|
| BR-AG-001 | Content AGENT แสดงผ่าน Referral link เท่านั้น | Must | เปิด URL ไม่มี token → ไม่พบหน้า / หน้าแจ้งให้ติดต่อตัวแทน; หน้าเป็น noindex |
| BR-AG-002 | การ์ดตัวแทนและปลายทาง Lead ตามเจ้าของลิงก์ | Must | ชื่อ/ใบอนุญาต/ช่องทางติดต่อตรงกับ seller ของ token; Lead จากฟอร์มและปุ่ม Sticky ถูกส่งถึงตัวแทนคนนั้น |
| BR-AG-003 | โปรโมชันตามกลุ่มของตัวแทน | Must | Carousel แสดงเฉพาะ Campaign Active ที่ผูกกับกลุ่มของตัวแทน; ตัวแทนไม่มีกลุ่ม → ไม่แสดง Section |
| BR-AG-004 | Section เฉพาะตัวแทน (AG-02–04) ไม่ปรากฏบนหน้าลูกค้า | Must | ข้อมูล AG-02–04 ไม่ถูกส่งไปหน้าลูกค้า; แสดงในหน้า Referral links (P-04) ของตัวแทน |
| BR-AG-005 | ชุดแชร์และ Sales kit ผ่านการอนุมัติพร้อม Content | Must | ตัวแทนเห็นเฉพาะชุดของ Version ที่ Approved; แก้ไขต้องออก Version ใหม่ |
